# 京阪南北版 実績表を「実物台紙スタイル」で出力（Phase 2-a レイアウト刷新）

- 日付: 2026-07-24
- 対象: `posting-automation` ／ ブランチ `feature/jisseki-daishi`（`feature/demo-share` から分岐）
- 種別: 既存機能「資料作成・変換表 > 京阪あて紙タブ > 挟み込み実績表」のレイアウト刷新

## 1. 背景・目的
- 大阪支社が実際に使っている「挟み込み実績表」は、`関西ぱどアプリ開発資料/関西ぱどアプリ開発.xlsx` の `実績表` シート。
  - 実物は **手書き記入用の台紙**：数字（コース通し番号）の上に**コース名を手書きで書き足し**、その下の縦長欄に**挟み込みチラシの案件名・枚数・完了者のサイン**を手書きしていた。
  - **挟み込みが無いコースもあり電子出力できず、これまで全部手書き**だった。
- 現行の Phase 2-a 実装 (`jisseki_rows`/`build_jisseki_workbook`) は「1地区1行の表形式」で出力しており、**実物の台紙とは見た目が違う**。
- 目的：**コース名・案件名・枚数まで印字**しておき、現場では**「サインするだけ」の状態**で印刷できるようにする（実物の書き方＝上にコース名・下に案件名/枚数/サイン、を崩さない）。

## 2. 要件（確定事項・2026-07-24 オーナー合意）
1. **単位＝コース＝担当地区**（1あて紙＝1コース）。
2. **対象＝挟み込みありのコースのみ**（挟み込みチラシ＝`size` 非空が1つ以上）。ぱどのみ地区は従来どおり除外。
3. **コース名＝`担当地区コード(6桁ゼロ埋め) + 半角スペース + 地区名`**（例 `024308 枚方・交野`）。地区名は既存 `chiku_name(version, chiku)`、コードは `area_code6`。
4. **各コースの中身＝挟み込みチラシを「案件名（配送物）＋枚数（その行の部数）」で1チラシ1行**に列挙。
5. **サイン欄は空**（完了者名は現場で手書き）。
6. **レイアウト＝中間案（台紙スタイル）**：実物の「上にコース名・下に案件名/枚数/サイン」の書き方を残しつつ、案件名が複数でも読めるよう幅を広げる。**1行に4コース**横並び、**A4横**想定。
7. **旧・表形式の出力は廃止し、新スタイルに一本化**（ボタンは1つ）。
8. 北版・南版の両方に対応（南版の地区名は 2026-07-23 のあて紙修正で解禁済）。

## 3. データモデル
既存 `common/atehagi.py` を再利用。行 (`row`) は `padonna / chiku / haisoubutsu(配送物=案件名) / busuu(部数=枚数) / size / gou / haifubi` を持つ。

新しい行生成関数（`jisseki_rows` を置換 or 拡張）が返す 1コース分の構造：
```
{
  "code": "024308",                 # area_code6(chiku)
  "chiku_name": "枚方・交野",         # chiku_name(version, chiku)
  "course_name": "024308 枚方・交野", # 上記2つを結合（印字するコース名）
  "flyers": [                        # size 非空の行のみ・元の並び順
     {"name": "SUUMOカウンター/注文住宅講座", "count": 400},
     {"name": "ECCジュニア/宮野教室", "count": 400},
  ],
}
```
- 生成順は既存 `group_by_chiku` の順（＝元データ順）を踏襲。
- 挟み込みチラシ 0 件のコースは含めない。

## 4. レイアウト仕様（build workbook）
新規 `build_jisseki_daishi_workbook(courses, version, gou, haifubi) -> bytes`。

- **タイトル行（1行目）**：`{M/D} ／ {gou}号　{版名}`（例 `6/26 ／ 1248号　京阪北版`）。太字・大きめ。日付は `haifubi` から `M/D`、版名は `_VERSION_LABEL`。
- **コースの並び**：**1行に4コース**。各コースは「案件名列（広め）＋枚数列（狭め）」の2列を占める → 4コース×2列＝**8列（A〜H）**。
  - 列幅目安：案件名列 ≈ 24、枚数列 ≈ 6。
- **1コース行 = 2つのExcel行**：
  - **ヘッダー行**：各コースの2列を結合し **コース名**（太字・センター・太枠）。
  - **本文行（縦長・折り返し）**：案件名列に各チラシ名を1行ずつ、枚数列に対応する枚数を1行ずつ（上詰め）。本文の最下部に**サイン用の空行**（例：末尾に「サイン：」ラベル＋空白 or 明確な空行1つ）。
    - 本文行の行高は、その4コースのうち**最大チラシ数＋サイン行**が収まる高さに設定。
- **罫線**：コースごとに太枠で区切り、内側は細罫（実物の雰囲気）。センター寄せ（コース名）／案件名は左寄せ・上詰め、枚数は右寄せ・上詰め。
- **端数**：コース数が4で割り切れない最終行は、余った枠は空セル（罫線あり/なしは実装で軽微決定・見栄え優先）。
- **印刷設定**：`orientation="landscape"`、`fitToWidth=1`、`pageSetUpPr(fitToPage=True)`。`print_area` を使用範囲に設定。生成 bytes は既存 `freeze_xlsx_bytes` で安定化。
- ファイル名：`{版名}_挟み込み実績表_{gou}号_{YYYYMMDD}.xlsx`（既存 `jisseki_filename` を流用/更新）。

## 5. UI（`pages/07_資料作成・変換表.py`）
- 京阪あて紙タブの「挟み込み実績表を生成」ボタンの出力を**新関数に差し替え**。旧 `build_jisseki_workbook`（表形式）は撤去。
- ボタン押下で `build_jisseki_daishi_workbook(...)` を呼び、DL。版・号・配布日はアップロード済みデータから取得（あて紙生成と同じ入力）。

## 6. 検証
- **単体（純関数 `jisseki_rows` 相当）**：
  - 複数チラシのコースで flyers が (案件名,枚数) 正しく並ぶ。
  - `size` 空の行（ぱど本誌・ぱどのみ地区）は flyers に入らない／ぱどのみコースは出力対象外。
  - `course_name` が「6桁ゼロ埋め＋地区名」。南版で先頭「9」が落ちない（例 `911001`→`911001`）、北版地区名も既存どおり。
- **ブック生成**：
  - コース枠数＝挟み込みありコース数。ヘッダーにコース名、本文に案件名/枚数、サイン欄が空。
  - 4コース/行の折り返し。タイトル・版名・印刷設定。
- **実データ突合（京阪北 1248号）**：
  - コース数が既存集計（挟み込みあり地区数＝実績表対象331件）と一致。
  - 各コースのチラシ数・枚数が元データ（配送管理表）と一致（サンプル数コースをゴールデン的に固定）。
- **実機E2E**：別ポート（例 8503）で起動し Playwright でアップロード→生成→DL。DL 実物を openpyxl で開き、コース名/案件名/枚数/サイン空/罫線を検証。
- 既存の全テストが緑のままであること（回帰）。

## 7. 非対象（YAGNI）
- 集計表・報告書・あて紙本体には触れない（実績表の出力レイアウトのみ）。
- 挟み込み無しコースの掲載（今回は対象外＝挟み込みありのみ）。
- 手書き項目（完了者サイン）の電子入力化はしない（現場手書きのまま）。

## 8. 未確定・軽微な実装判断
- 1行4コース確定。案件名が列幅を超える場合は折り返し（省略はしない）。実データで見て極端に崩れる場合のみ列幅を微調整。
- サイン欄の見せ方（空行 or 「サイン：」ラベル）は実機1枚をオーナー目視で確定。
