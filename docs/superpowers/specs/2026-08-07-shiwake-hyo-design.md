# 仕分け表 設計（C）

作成: 2026-08-07 ／ ブランチ `feature/shiwake-hyo`（`feature/demo-share` から分岐）

## これは何か

倉庫に納品されたチラシを**配布員ごとの山に分ける**ための作業チェック表。
作業員が1枚ずつ持って、仕分けし終えたチラシにチェックを入れる。

オーナーの言葉（2026-08-07）:
> 倉庫に納品されたチラシを配布員に渡すために、配布員ごとに仕分けるためのチェック表。
> 配布員ごとに受け渡す山をつくるから**配布員ごとに合計**してほしい。

## 入力

**配送管理表**（`Downloads\【京阪南】20260821配送管理表 (1).xlsx` の形）。
既存の あて紙・集計表 が読む「その他配送管理表」とは**別のファイル**だが、**列は同じ17列**。

| 使う列 | 用途 |
|---|---|
| `ぱどんな` | **配布員名**（1枚の単位） |
| `配送順位` | ヘッダに出す。例 `9101-04-01` |
| `異動` | **「休」の人は仕分け表に入れない**（オーナー指示） |
| `配送物` | チラシ名 |
| `配布部数` | 部数 |
| `チラシサイズ` | Ｂ３/Ｂ４/Ａ４。**空＝ぱど本誌 → 「情報誌」と書く** |
| `号数` `配布日` | 表紙情報 |

京阪**南**版・**北**版の両方で使う。列が同じなので処理は共通。

## 出力

`.xlsx` 1ファイル。**1シートに全員を並べ、1人ごとに改ページ**（＝印刷すると1人1枚）。
シートを人数分に分けないのは、24人なら24シートになり一括印刷しづらいため。

1人分のかたち:

```
2026/08/21  1213号
配布員: 松岡  直美          配送順位: 9101-04-01
┌────────────────────────┬────────┬────────┬──────┐
│ チラシ名                │ 部数   │ サイズ │ 済   │
├────────────────────────┼────────┼────────┼──────┤
│ 91 ぱど                 │  1,131 │ 情報誌 │      │
│ おたからや寝屋川店・萱島駅前店 │    438 │ Ｂ４   │      │
│ 業務スーパー             │  1,131 │ Ｂ４   │      │
├────────────────────────┼────────┼────────┼──────┤
│ 合計                    │  2,700 │        │      │
└────────────────────────┴────────┴────────┴──────┘
```

- **部数は配布員ごとの合計**（松岡さんは2地区持ちだが、業務スーパーは 438+693=1,131 と1行にまとめる）
- チェック欄（「済」）は**空欄**。作業員が手で書く
- 並び順：**配送順位の昇順**。空の人は末尾

## 実測して確かめた前提（2026-08-07・`【京阪南】20260821配送管理表 (1).xlsx`）

| 確認したこと | 結果 |
|---|---|
| 明細 | 68行・配布員 25名 |
| 配送順位を複数持つ配布員 | **0名**（1人1つ） |
| 配送順位が空の配布員 | 1名（＝休の井上さん。除外対象と一致） |
| `異動` に入る値 | **None と「休」の2種類のみ**（休は2行） |
| 部数が空の行 | **0** |
| 配送物が空の行 | **0** |
| 休を除いた人数 | **24名** → 24ページ |

⚠️ **北版の配送管理表は手元に無い。**（`Downloads` にあるのは京阪南のみ）
列が同じなので動くはずだが、**実データでの確認はできていない**。オーナーに1本もらいたい。

### 🔴 黙って落とさない

- `異動` に「休」以外の見慣れない値があったら、**その人は残したうえで画面に警告**を出す。
  勝手に除外して人数が減るのが一番こわい。
- 除外した人数を画面に出す（「休 1名を除いて 24名分を作成しました」）。

## テスト

| # | 守ること |
|---|---|
| 1 | 配布員ごとにチラシが合算される（松岡さん 業務スーパー = 438+693 = 1,131） |
| 2 | 「休」の人が**1人も含まれない** |
| 3 | 「休」以外の異動値は**除外されない**（＋警告が返る） |
| 4 | チラシサイズが空のとき「情報誌」になる |
| 5 | サイズがあるときはその値のまま（Ｂ４→Ｂ４。全角のまま変えない） |
| 6 | 配送順位が `9101-04-01` の形で出る（`9101/4/1` にならない） |
| 7 | 並び順が配送順位の昇順、空は末尾 |
| 8 | 人数ぶんの改ページが入る |
| 9 | 各人の合計が items の合計と一致 |
| 10 | 実データ（京阪南 8/21号）で **24名**・松岡さんが上の値と一致 |
